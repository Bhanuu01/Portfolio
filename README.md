# Portfolio

This repository contains an earlier React portfolio site built with Vite and Tailwind.

It is separate from the newer GitHub Pages portfolio at [bhanuu01.github.io](https://bhanuu01.github.io/). I am keeping this repo because it shows an earlier iteration of how I structured my profile, projects, and experience in code.

## What is in this repo

- a React single-page portfolio
- section-based layout for hero, about, skills, projects, experience, and contact
- portfolio data stored in `src/data/portfolioData.jsx`
- animation and interaction libraries such as Framer Motion and React Type Animation

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Repository structure

- `src/components/`
  UI sections such as hero, navbar, projects, experience, and contact.
- `src/data/portfolioData.jsx`
  Personal info, project content, skills, and experience data used by the site.
- `public/`
  Static assets.

## Running locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
